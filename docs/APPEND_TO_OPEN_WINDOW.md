# Добавление в открытое окно — 1.0.8

На вкладке **3D Print** остаются обычные кнопки **Open in OrcaSlicer**, **Open in Bambu Studio**, **Open in PrusaSlicer**. Они экспортируют 3MF и запускают выбранную программу с этим файлом, как раньше.

Три новые кнопки:

- **Add to open OrcaSlicer**
- **Add to open Bambu Studio**
- **Add to open PrusaSlicer**

Открой слайсер с нужным проектом, вернись в SOLIDWORKS и нажми соответствующую кнопку **Add to open …**. При одном подходящем окне оно выбирается автоматически. При нескольких окнах появится список заголовков и PID. При отсутствии открытого окна новый экземпляр не запускается.

## Что передаётся

Для режима добавления создаётся **бинарный STL в миллиметрах**, содержащий только геометрию. В сообщении импорта нет принтера, профилей материала, команд открытия/сброса проекта или удаления существующих объектов. STL не сохраняет цвета, материалы и отдельную структуру компонентов сборки: вся активная модель экспортируется в один файл. Текущая настройка точности триангуляции SOLIDWORKS сохраняется.

Параметры STL (единицы, бинарный формат, экспорт сборки в один файл, информационные окна, предпросмотр и проверка пересечений) меняются только на время экспорта и затем восстанавливаются. Незавершённый или пустой STL не отправляется.

Слайсер выполняет импорт асинхронно. Он может показать свои обычные вопросы о геометрии, масштабе или расположении. Сообщение об успешной передаче не означает, что дополнение проверило результат на столе. Положение и раскладка объектов определяются слайсером.

## Временные файлы

Открыть через **Win + R**:

```text
%TEMP%\SolidWorksSlicerBridge
```

Это подкаталог `Path.GetTempPath()` для пользователя, от которого работает SOLIDWORKS. При обычной установке Windows это `%LOCALAPPDATA%\Temp\SolidWorksSlicerBridge`, но переменные окружения или настройки Windows могут задавать другое расположение.

Обычный экспорт создаёт `.3mf`; добавление в открытое окно — `.stl`. Имена содержат название модели и время экспорта. После успешного экспорта/отправки дополнение удаляет из этой папки `.3mf` и `.stl`, время изменения которых старше семи дней. Это не фоновый таймер. Закрытие SOLIDWORKS само по себе файлы не удаляет. После сохранения проекта слайсера и окончания работы ненужные экспортные файлы можно удалить вручную. До завершения импорта удалять их нельзя; для последующей функции Reload/перезагрузки геометрии исходный экспортный файл также должен оставаться доступным.

Иконки и журнал — в других папках:

```text
%LOCALAPPDATA%\SolidWorksSlicerBridge\icons
%LOCALAPPDATA%\SolidWorksSlicerBridge\logs\addin.log
```

## Передача и ограничения

Дополнение находит главное окно по исполняемому файлу, классу `wxWindowNR` и свойствам `Instance_Hash_Minor` / `Instance_Hash_Major`. Перед отправкой повторно проверяются HWND, PID, время запуска процесса, путь EXE и доступность окна. Буфер обмена, имитация клавиш и автоматическое изменение настроек слайсера не используются.

Передача выполняется через `WM_COPYDATA` с `dwData=1` и строкой UTF-16. OrcaSlicer, Bambu Studio и PrusaSlicer до 2.9.0 получают список аргументов C-style; PrusaSlicer начиная с 2.9.1 получает JSON-конверт `type=CLI`. Версия PrusaSlicer читается из EXE; неизвестная версия не угадывается. Этот внутренний протокол может измениться в будущих версиях слайсеров.

Запускай SOLIDWORKS и слайсеры с одинаковым уровнем прав, желательно без запуска от администратора. Закрой модальные окна в слайсере перед добавлением. При тайм-ауте передачи (5 секунд) автоматического повтора нет: сначала проверь слайсер, поскольку запрос мог уже попасть в очередь и повторная отправка создаст дубликат.

## Проверки

Windows CI компилирует исходники дополнения с ограниченными имитациями API SOLIDWORKS. Проверяются девять COM-обработчиков, семь команд, встроенные иконки и однократное обновление вкладки. Отдельные реальные Windows-процессы с тестовыми окнами проверяют поиск получателя, Unicode/пробелы/точку с запятой в путях, оба формата IPC, адресную доставку одному из нескольких окон, блокировку модальных окон и ограничение времени ожидания. Имитация экспорта проверяет восстановление настроек после успеха и нескольких типов ошибки.

Тестовые процессы не являются настоящими слайсерами. Тесты не подтверждают импорт и отображение модели внутри настоящих SOLIDWORKS 2026, OrcaSlicer, Bambu Studio или PrusaSlicer. Это отдельная проверка на рабочем компьютере. Тестовые EXE и API-заглушки не входят в установщик.
